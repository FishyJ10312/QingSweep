## 强制退出与重启核对

对普通文件清理、应用私有目录清理、批次恢复，分别在以下窗口终止专用测试进程，共 **9 个真实 SIGKILL 场景**：

1. 操作意图已经落盘，尚未移动文件。
2. 文件刚完成移动，结果尚未写入日志。
3. 单项结果已经落盘，批次尚未完成。

重启后核对恢复项数量、去重、批次摘要和默认选择。随后通过生产批次恢复逻辑恢复生成的文件，校验原始字节一致。未处理的后续文件留在原位置，未沿用旧的手动选择或删除确认。

额外覆盖日志提交失败前后、恢复目标被占用、摘要丢失后的重建、损坏日志、无效事件、旧记录首次恢复，以及操作意图保存后立即停止。

写入失败使用 SQLite 提交边界故障注入，未将真实用户磁盘写满。SIGKILL 测试也不是实机断电测试。

## 原生界面走查

使用临时文件，实际完成：默认未选 → 手动全选 → 取消项目选择 → 复核 → 二次确认 → 清理中途终止进程 → 重启核对 → 应用内批次恢复。

共执行两次专用原生进程中断。第二次使用最终引擎，在文件已移动、结果未落盘时终止，重启后找回并恢复。另观察到未授权时的具体提示，以及用户授权后实际读取成功；更换最终交付包后，本机访问授权保持开启。

所有恢复文件均核验字节一致，临时项目未被移动；夹具随后移除，真实用户清理历史保留。原生界面走查不计入上表的 624 项自动检查。

## 交付完整性

- 交付的应用二进制与本机已验收安装版本一致。
- ZIP 解压后通过 `codesign --verify --deep --strict`，源码附件与整理后的发布源码逐文件一致。
- 本机自签名与 Hardened Runtime 不等于 Developer ID，也不等于 Apple 公证。
- 发布附件提供 SHA-256，下载后可重新核对。
- 公开源码与附件不包含本机扫描数据库、用户清理历史、签名私钥或钥匙串密码。

机器可读记录：[validation-1.8.1-beta.json](validation-1.8.1-beta.json)。
