## 英文原生界面实测

专用原生测试程序使用生产界面与清理引擎，数据目录与用户实际数据隔离。只使用生成的临时文件，实际走通：

1. 素材和项目初始不勾选。
2. 手动选择后切到 English，选择保留，中文文件名不翻译。
3. 手动全选、取消单项，取消项目选择后进入复核。
4. 英文复核和二次确认；未勾确认框时不能执行。
5. 一个临时视频移到废纸篓，进入清理记录，再按批次恢复。
6. 恢复文件字节与原始内容一致；项目及其他夹具文件字节未变。
7. 英文搜索找到旧中文索引中的归属；进入文件夹后可返回上级。
8. 英文工具页正常；重启保留语言，跟随系统可恢复中文。

首轮发现组合计数仍显示中文「项」以及复核弹窗的语言环境不一致，均已修复并重新实测。原生流程不计入自动检查数量。

实际用户清理历史和独立操作日志与测试前备份字节一致。测试程序使用独立目录。

## 延续的崩溃恢复检查

本轮保留并运行 **9 个真实 SIGKILL 窗口**：普通清理、应用数据清理、批次恢复，分别在意图落盘后、文件移动但结果未落盘、逐项结果已落盘后终止。重启核对身份、不重复恢复、不沿用删除确认，恢复后验证原始字节。

1.8.1 的原生验收还实际终止过两次专用进程并重启恢复，历史说明见 [1.8.1 发布记录](RELEASE_1.8.1_BETA.md)。这些不是断电测试。日志写入故障使用注入，没有写满用户磁盘。

## 交付与边界

- 实机环境：Apple Silicon / macOS 27.2。编译最低 macOS 14，不等于 macOS 14 实机验收通过。
- 固定应用标识和本机签名身份，包含双语资源、MIT 与第三方署名，启用 Hardened Runtime。
- 发布包检查解压内容、签名完整性与 SHA-256；源码不包含个人扫描库、清理历史和签名秘密。
- 保留原有 1.8.1 发布与附件。
- **未使用 Developer ID 签名，未 Apple 公证。** GitHub 开源发布不以公证为前提。
- 仍待验证：另一台 Mac 默认 Gatekeeper 的首次启动、macOS 14 实机、更多文件系统和真实外置盘拔插。

本机安全评估原本不是默认开启状态，本轮没有修改。不能将本机可启动当成其他 Mac 默认安全设置下的安装验收，因此继续标为 **Beta / Pre-release**。
