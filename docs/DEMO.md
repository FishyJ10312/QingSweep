The captures are from the published 1.8.6 build (21), run as separate demo copies with dedicated profiles on a temporary disk image. Each language used a fresh set of generated files. The installer was a disposable example and the version comparison used generated application metadata.

In each walkthrough, the app moved one older installer and one cache file to the demo volume's Trash, then restored both to their original locations from History. Content hashes matched after restore. The generated video, project and log stayed in place. The app window and dialogs are shown with path details collapsed. The GIF and MP4 use edited step timing.
